Click the port display to open localhost:<port>, or reveal the project folder in Finder.

Stops cleanly

The ⏻ button sends SIGTERM to the process group, then SIGKILL if it's still alive after 3 seconds — so parent processes like pnpm dev go away too.

Always up to date

Rescans in the background when you open the panel and every 3 seconds. No Dock icon — it stays quietly in the menu bar.

Reading the LEDs

The menu bar icon and the panel follow the same rules.

  • Green power LED — the server is running. In the menu bar, one lights up per server from the top (up to 3).
  • Activity LED — blinks in proportion to CPU usage (red in the menu bar, amber in the panel). Every 0.9 s when idle, every 0.07 s when busy.
  • Blinking red power LED — the server is stopping.
  • Unlit LED — an empty slot. With no servers, the blinking stops too.

Install

macOS 14 Sonoma or later, on Apple Silicon and Intel.

With Homebrew

brew install --cask silqwer/tap/devservers

It opens right away with no security warning. Update with brew upgrade --cask devservers — the upgrade quits the app, so open it again afterwards. To launch it at login, add it under System Settings → General → Login Items.

Manual download

  1. Download DevServers.zip and unzip it.

  2. Move DevServers.app to your Applications folder.

  3. Open it. On first launch macOS asks you to confirm an app downloaded from the internet — click Open.

  4. That's it once the rack icon appears in your menu bar. To launch it at login, add it under System Settings → General → Login Items.

Safe to use. It's signed with a Developer ID and notarized by Apple, so there's no "unidentified developer" warning. Because it has to inspect and stop other processes, it doesn't use App Sandbox — which is why it's distributed directly instead of through the Mac App Store. All the code is public on GitHub.

Build from source

All you need is Xcode or a Swift 5.10+ toolchain.

git clone https://github.com/silqwer/devservers.git
cd devservers
./build.sh                       # build/DevServers.app
open build/DevServers.app

swift run devservers-scan --all  # print scan results in the terminal

How does it find servers?

Only built-in macOS commands. PIDs are batched into a single query, so one scan takes about 0.3 seconds.

StepCommandPurpose
1lsof -iTCP -sTCP:LISTEN -n -PListening ports and PIDs
2lsof -a -p <PID…> -d cwd -FpnEach process's working directory
3<cwd>/package.jsonProject name
4ps -o pid=,pgid=,%cpu=,command=Process group · CPU · command line → kind
