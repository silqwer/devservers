:5173포트를 누르면 브라우저로

포트 LCD를 누르면 localhost:포트가 열려요. Finder에서 프로젝트 폴더 열기도 한 번에.

깔끔하게 종료

⏻ 버튼은 프로세스 그룹에 SIGTERM을 보내고, 3초 안에 안 꺼지면 SIGKILL. pnpm dev 같은 부모 프로세스까지 정리돼요.

항상 최신 상태

메뉴를 열 때와 3초마다 백그라운드에서 다시 스캔해요. Dock 아이콘 없이 메뉴바에만 조용히 있어요.

LED 읽는 법

메뉴바 아이콘과 패널의 LED는 같은 규칙을 따라요.

  • 초록 전원 LED — 서버가 켜져 있어요. 메뉴바에서는 서버 수만큼 위 칸부터 켜져요 (최대 3칸).
  • 활동 LED — CPU 사용량에 비례해 깜빡여요 (메뉴바는 빨강, 패널은 주황). 한가하면 0.9초, 바쁘면 0.07초 간격.
  • 빨강 전원 LED 점멸 — 서버를 끄는 중이에요.
  • 꺼진 LED — 빈 슬롯. 서버가 없으면 깜빡임도 멈춰요.

설치

macOS 14 Sonoma 이상, Apple Silicon · Intel 모두 지원해요.

Homebrew로 설치

brew install --cask silqwer/tap/devservers

보안 경고 없이 바로 실행돼요. 업데이트는 brew upgrade --cask devservers — 업데이트 중에 앱이 종료되니 끝나면 다시 열어 주세요. 로그인할 때 자동으로 켜려면 시스템 설정 → 일반 → 로그인 항목에 추가하세요.

직접 내려받기

  1. DevServers.zip을 내려받아 압축을 풀어요.

  2. DevServers.app을 응용 프로그램 폴더로 옮겨요.

  3. 앱을 실행해요. 처음 한 번은 "인터넷에서 다운로드한 앱"이라는 확인 창이 뜨는데, 열기를 누르면 돼요.

  4. 메뉴바에 랙 아이콘이 나타나면 끝. 로그인할 때 자동으로 켜려면 시스템 설정 → 일반 → 로그인 항목에 추가하세요.

안심하고 쓰셔도 돼요. Developer ID로 서명하고 Apple 공증을 받아서 "확인되지 않은 개발자" 경고가 뜨지 않아요. 다른 프로세스를 조회하고 종료해야 해서 App Sandbox는 쓰지 않고, 그래서 Mac App Store 대신 직접 배포해요. 코드는 모두 GitHub에 공개되어 있어요.

소스에서 빌드

Xcode 또는 Swift 5.10+ 툴체인만 있으면 돼요.

git clone https://github.com/silqwer/devservers.git
cd devservers
./build.sh                       # build/DevServers.app
open build/DevServers.app

swift run devservers-scan --all  # 터미널에서 스캔 결과만 확인

어떻게 찾나요?

macOS 기본 명령만 써요. 여러 PID는 한 번에 묶어 조회해서 스캔 한 번에 약 0.3초.

단계명령용도
1lsof -iTCP -sTCP:LISTEN -n -PLISTEN 중인 포트와 PID
2lsof -a -p <PID…> -d cwd -Fpn프로세스의 작업 디렉터리
3<cwd>/package.json프로젝트 이름
4ps -o pid=,pgid=,%cpu=,command=프로세스 그룹 · CPU · 실행 명령 → 종류
